# 自由者画布

自由者画布是一款本地优先的 AI 图片与视频无限画布，支持连接 ComfyUI、管理云端图片/视频 API、组织提示词与素材，并在节点画布中执行生成工作流。

当前版本：**0.18.58**

## 0.18.58

- 修复图片、视频和首尾帧任务参数面板在画布放大后超出窗口、底部内容不可见的问题。
- 面板宽高会根据当前画布缩放比例和窗口尺寸自动限制，不再允许无限放大。
- 拖动节点、缩放面板或改变窗口尺寸后，面板会自动回到可视区域。
- 面板顶部操作栏改为吸附显示，滚动时仍能看到缩放和关闭按钮。

- 加强首尾帧视频、ComfyUI 工作流识别和错误提示。

## 隐私与安全

- 仓库和发布包不包含 API Key、个人画布、生成历史或本机 ComfyUI 工作流。
- API Key 使用 Electron `safeStorage` 加密后保存在当前 Windows 用户的数据目录中。
- 项目保存于本机；连接云端模型时，仅向用户自行配置的 API 服务发送生成请求。

## 设计原则

自由者是独立实现的本地 AI 无限画布，不包含其他平台的代码、商标或专有素材。
